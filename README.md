# Anuj Mane — Web Developer Portfolio

A responsive starter portfolio built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Edit `index.html` and `style.css` to personalize the content and colors.

## Personalize before publishing
- Update the GitHub and LinkedIn links in `index.html` to your actual profiles.
- Replace `hello@example.com` with an email address you want to use publicly.
- Add a real profile photo only if you want to.
- Update project cards as you actually build and publish them. Cards currently marked concept/planned are examples, not completed work.
- Only list technologies and skills you can honestly discuss.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `anuj-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In repository Settings, open Pages.
4. Select deployment from the `main` branch and the root folder, then save.
5. Use the Pages URL shown by GitHub after publishing finishes.
